# Dashboard - Sistema de Detecção de Fumaça

Interface web para monitoramento e gerenciamento do sistema de detecção de fumaça por Inteligência Artificial.

## Funcionalidades

- Monitoramento de eventos e alertas de fumaça
- Visualização e gerenciamento de câmeras
- Painel do operador e área técnica
- Gerenciamento de usuários e notificações
- Logs de auditoria
- Monitoramento e controle do serviço de detecção

## Tecnologias

React, Vite, React Router e integração com API REST em FastAPI.

## Desenvolvimento

Instale as dependências com `npm install` e inicie o ambiente com `npm run dev`.

Aplicação disponível por padrão em `http://localhost:5173`.

Para gerar o build de produção, utilize `npm run build`.

## Segurança

Credenciais e configurações privadas não são versionadas. Utilize variáveis de ambiente para configurações locais.
